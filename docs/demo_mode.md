# Демо режим за журито (HX-02)

Един клавиш пуска сценарий от около 3 минути, който показва основните механики на играта. Сценарият е фиксиран и се изпълнява еднакво при всяко пускане, така че на сцената не може да се обърка.

Код: `Game/includes/game_demo.h`, `Game/scr/game_demo.cpp` (директор, действия), `Game/scr/game_demo_script.cpp` (сценарият), `UI/scr/UI_demo.cpp` (надписи и ефекти), тест `scratch/test_demo_mode.cpp`.

## Пускане

| Как | Какво става |
|---|---|
| **F9** в главното меню | започва демото (в менюто долу има подсказка „[F9] ДЕМО ЗА ЖУРИТО“) |
| `energy_crisis.exe --demo` | играта тръгва направо с демото |
| всеки клавиш, бутон на мишката или геймпада, **Esc** | връщане в главното меню (F11, Alt, Ctrl, Shift и Win не прекъсват демото) |
| `EC_DEMO_SPEED=4` | репетиция 4 пъти по-бързо (до 30 стъпки на кадър) |
| `EC_DEMO_SHOTS=папка` | запазва PNG на всеки надпис: готови кадри за презентацията |

Губенето на фокуса не паузира демото. Когато сценарият свърши, остава финалният екран с надпис „Натиснете клавиш за връщане в менюто“.

## Защо е сигурно

- **Фиксирано зърно.** Всеки демо мач започва със `Demo::DEMO_SEED` (2026), независимо от `EC_SEED` и часовника.
- **Фиксирана стъпка.** `DemoDirector` движи енджина на стъпки от 1/60 s. Бавен или бърз лаптоп, 30 или 144 FPS: резултатът е един и същ до последния бит. Демото върви навреме дори при 2 FPS (до 30 стъпки на кадър); на още по-бавна машина просто върви по-бавно.
- **Без случайни щети.** Докато върви демото, случайните мълнии не чупят сгради. Чупи се само това, което пише в сценария.
- **Без бот и без въвеждане.** Двете страни се управляват само от сценария, а уроците, паузата и диалозите са изключени.
- **Грешка не спира шоуто.** Ако действие липсва, хвърли изключение или върне `false`, директорът го записва в конзолата (`[Demo] ...`) и продължава.
- **Тест.** `scratch/test_demo_mode.cpp` изпълнява целия сценарий без графика и проверява, че всеки ден завършва както казва надписът, че Западът печели и че резултатът е еднакъв при различни FPS и `EC_SEED`.

Тези бийтове вече са в сценария, но се прескачат (без надпис), докато някой не регистрира действието им. Когато функцията се слее, регистрирайте действието и бийтът оживява сам, без промяна в сценария.

| Действие | Аргументи | Функция | Време |
|---|---|---|---|
| `event.card` | `id=random` | Тесте с градски събития (F-09) / големи събития (HX-09) | 1:16 |
| `nuclear.build` | `player=1` | Ядрена централа | 1:35 |

## Как се добавя действие

```cpp
#include "game_demo.h"

// В .cpp файла на вашата функция (енджин): регистрация при стартиране
static Demo::DemoActionRegistrar regNuclear("nuclear.build",
    [](Demo::DemoContext& ctx, const Demo::DemoArgs& args) {
        int player = args.getInt("player", 1);
        bool ok = myNuclearBuild(ctx.engine, player);       // вашият код
        Demo::DemoCue cue;                                  // по желание: ефект в UI
        cue.kind = "nuclear.build";
        cue.player = player;
        cue.text = "ЯДРЕНА ЦЕНТРАЛА!";                      // UI го показва като плаващ надпис
        ctx.cue(cue);
        return ok;                                          // false = записва се като грешка, шоуто продължава
    });
```

UI функции (авария, табло) могат да регистрират действие и по време на работа, например в конструктора си, като ламбдата хваща своя обект: `Demo::registerDemoAction("dashboard.show", [this](auto& ctx, auto& args) { open(args.getFloat("seconds", 5)); return true; });`.

`DemoEngineAccess` дава привилегировани операции върху енджина: време, ден, дял на града, победител, безплатен парцел, принудителен строеж.

## Как се добавя бийт

Сценарият е само данни (`Game/scr/game_demo_script.cpp`):

```cpp
s.push_back(DemoBeat(55.0f).say("МЪЛНИЯ!", "Мълния унищожи слънчев панел на Изтока")
                .act("lightning", "player=2 cell=8,0 hit=1"));
```

- `say(надпис, подзаглавие)`; `title(...)` е заглавен екран на цял екран.
- `act(име, "ключ=стойност ...")`, като стойностите може да са в кавички: `text="Здравей, жури!"`.
- `speed(×)` сменя скоростта на играта, `holdFor(s)` задава колко дълго стои надписът (0 = до следващия надпис).
- `todo("функция")` прави бийта незадължителен.
- В надписите може да се ползват `{result}` `{day}` `{p1}` `{p2}` `{demand}` `{mw1}` `{mw2}` `{season}`.

Клетките `c,r` са решетката 9 × 12 на играча (3 × 3 клетки на парцел). Запад: начален парцел = клетки 0..2 × 0..2, брегът е 6..8. Изток: начален = 6..8 × 0..2, брегът е 0..2.

## Вградени действия

| Действие | Аргументи | Какво прави |
|---|---|---|
| `weather` | `player=0/1/2 type=sunny/windy/rainy/stormy/snowy/cloudy [lock=1]` | налага времето; при `lock=1` то остава и след смяната на деня |
| `unlock_weather` | `player` | връща случайното време |
| `season` | `type=spring/summer/autumn/winter [hour]` | скок в първия ден на сезона |
| `jump_day` | `day hour` | скок в ден и час; търсенето следва графика, дяловете остават |
| `advance` | `hours` или `to_hour` | симулира напред |
| `settle` | | досимулира деня до 06:00 и прави истинското дневно отчитане |
| `build` | `player type=solar/wind/hydro/battery/lamp cells=c,r;c,r [pay=1]` | строи по истинските правила; парцелът и ресурсите се дават безплатно |
| `buy_plot` | `player plot=ред,колона` | безплатен парцел |
| `mine` | `player res=wood,iron,... times` | истински добив |
| `grant` | `player wood= iron= ... gold= money=` | дава ресурси |
| `lightning` | `player cell=c,r [hit=1]` | мълния по сценарий (`hit=1` унищожава сградата в клетката) |
| `share` / `demand` | `p1=0.6` / `mw=120` | задава дела на града / търсенето |
| `winner` | `player [ifnone=1] [share] [text]` | обявява победител |
| `notice` / `message` | `text` | плаващ надпис / съобщение в града |
| `timescale` / `noop` | `value` / | скорост / нищо |
